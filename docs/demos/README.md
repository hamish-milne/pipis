# Demos

Whole apps built with pipis, running here, each with its source. The examples in the guide are small and show one thing; these show how the pieces fit together.

- [Todo list](todo.md): array state, a row for each item, and reordering.
- [Weather](weather.md): loading data with `Suspense`, and a theme kept in storage.
- [Feedback](feedback.md): context, portals, a modal, and an error boundary.

The demos are styled with [Tailwind CSS](https://tailwindcss.com), which is not part of pipis: any way of writing CSS works, because an element is an ordinary DOM node with an ordinary `class`.
